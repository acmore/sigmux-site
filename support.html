Support

Updated October 5, 2026
Sigmux is an SSH terminal for iPhone, made for people who live in tmux and run coding agents on their own machines. Questions, bugs and requests: hezj07@gmail.com. Replies usually within two days.

Reporting a problem

Include the build number (Settings → About), your iPhone model and iOS version, the host's OS and tmux version (tmux -V), and which connection mode you use (shell, tmux, or control mode). For connection or display problems, turn on Settings → Diagnostics → Connection trace, reproduce the problem, then share the trace files from the Sigmux folder in the Files app. Traces contain host names and terminal output; look through them before sending.

Getting started

  • Add a host — hostname or IP, port, username, and a password or an SSH key. Keys can be imported, or generated on the phone and installed on the host from the app.
  • Connect to — Shell opens a plain login shell. tmux attaches to a session on the host like a desktop terminal would. Control mode uses tmux's -CC protocol so windows and panes become native controls; it needs tmux 3.3 or newer on the host.
  • Agents — Settings → Agents installs small hooks on a host so Claude Code, Codex and OpenCode can notify your phone and take answers from it. The host needs python3; Sigmux's own push notifications also need OpenSSL 1.1.1 or newer (any current macOS or Linux has both).

Notifications

Notifications from your hosts travel sealed through a relay we run and are opened on your phone; the relay cannot read them. If a host's test notification fails, the error names the cause: the host can't reach push.acmore.dev, the install is out of date, or notifications are off for Sigmux in iOS Settings. Bark, ntfy and webhooks remain available as alternatives.
